Entry for the [One Line, Big Laugh](https://make.fun/bounty/u-coral-404-one-line-big-laugh-328fb857) bounty on make.fun: a program that writes a single hilarious line of at most 200 characters to `/output/entry.txt`.

## The line

> I hit snooze 14 times this morning. My alarm clock filed for overtime, HR approved it, and I got the bill.

## Run

```sh
node main.ts
cat /output/entry.txt
```
